CRITICAL FEATURE: Fuzzy Question Similarity Detection
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Algorithm:
```python
from difflib import SequenceMatcher

# Step 1: Normalize question
normalized = ' '.join(question.lower().split())

# Step 2: Calculate similarity
similarity = SequenceMatcher(None, q1_normalized, q2_normalized).ratio()

# Step 3: Group if similar (threshold: 0.60)
if similarity >= 0.60:
    q2['group_id'] = q1['group_id']  # Same group
```
