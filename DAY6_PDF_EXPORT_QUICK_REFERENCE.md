## 🐛 Troubleshooting

### Issue: "PDF not found" error
**Solution:** Generate a predicted paper first (upload ≥5 papers)

### Issue: Download not starting
**Solution:** Check if `pdf_available=True` in template context

### Issue: Permission denied
**Solution:** Ensure `static/generated/` directory has write permissions

### Issue: Import error for reportlab
**Solution:** Run `pip install reportlab==4.0.7`
